# Apps Directory

This directory contains the executable user-facing applications built on top of the Axiom platform.

## Application Modules
- **mission-control**: The primary cognitive management dashboard and reasoning graph console.
- **studio**: Creative tool workspaces (Photo, Vector, Brand) containing canvas rendering engines.
- **admin**: Platform administration, licensing, and billing surfaces.
- **analytics**: Aggregated telemetry metrics and user action reporting.
