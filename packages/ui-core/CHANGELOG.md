# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-06-21
### Added
- Implemented `Divider` component supporting horizontal/vertical orientations, spacing, and label slots.
- Implemented `Icon` component supporting inline tree-shakeable SVG registry, sizing, coloring, and spinner animation.
- Implemented `Badge` component supporting variants, sizes, custom dots, and leading icons.
- Implemented `Button` component supporting polymorphic tags, interactive hover/active states, and loading states.
- Added performance benchmarks under `tests/perf.bench.ts`.

## [0.1.0] - 2026-06-21
### Added
- Initial release of `@axiom/ui-core`.
- Implemented `Surface`, `Text`, `Stack`, and `Grid` layout primitives.
