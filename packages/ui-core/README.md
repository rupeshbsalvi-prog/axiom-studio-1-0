# @axiom/ui-core

Core visual primitives and layout components for the Axiom Design System.

## Components
- **Surface**: Visual container representing cards, panels, and layouts.
- **Text**: Typographic primitive for headers, subheadings, labels, and body copy.
- **Stack**: Flexbox container managing layout flow, alignment, and gaps.
- **Grid**: CSS Grid layout container managing responsive column grids.
