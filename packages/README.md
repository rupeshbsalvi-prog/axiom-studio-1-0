# Packages Directory

This directory contains the reusable shared libraries and cognitive/design packages consumed by Axiom applications.

## Packages Matrix
- **tokens**: Core design system tokens (colors, typography, spacing, motion variables).
- **ui-core**: Reusable primitive components (Button, Input, Checkbox, Switch, etc.).
- **workbench**: Reusable composite layout elements (Sidebar, Dock, Inspector, Tree View).
- **runtime**: Axiom Platform Runtime v5 core services and EventBus adapters.
- **telemetry**: Pure derived telemetry calculation engine (TelemetryEngineV1).
- **explainability**: Pure derived explanation mapping engine (ExplanationEngine).
- **cognition**: Core Brain X Mission and Reasoning Graph engines.
