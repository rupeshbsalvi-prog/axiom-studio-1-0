# Changelog

All notable changes to the `@axiom/ui-foundation` package will be documented in this file.

## [0.1.0] - 2026-06-21

### Added
- Initial release of presentation-free design system utilities.
- Implemented polymorphic type helpers and polymorphic forwardRef.
- Implemented classNames compose utility.
- Implemented slot composition via `<Slot>`.
- Implemented narrow token variants class mapper and state data-attributes mapper.
- Implemented base, variant, slot, and accessibility contracts.
- Implemented comprehensive accessibility helper suite (useId, keyboard activation, motion, escape, arrow navigation, ARIA maps).
