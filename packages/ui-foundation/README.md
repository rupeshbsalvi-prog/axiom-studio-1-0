# @axiom/ui-foundation

Core presentation-free shared primitives and rendering contracts for the Axiom Studio design system.

## Modules

- **types**: Polymorphic rendering contracts (`as` prop).
- **react**: React helpers (`forwardRef`).
- **runtime**: Class composition (`classNames`), states to data-attributes (`dataAttributes`), slots composition (`Slot`), token mapping (`variants`), and accessibility helpers.
- **contracts**: Universal component interfaces.
