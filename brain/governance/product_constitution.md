# Product Constitution v1.0

This constitution defines the immutable product behavior laws governing Axiom Studio's UX interfaces, protecting user cognitive flow and preventing visual noise.

---

## The Six Laws of UX Behavior

- **Law 1 — Intent First**: Brain X derives structure from user intent; users never model tasks manually. The user expresses intent; Brain X derives the structure.
- **Law 2 — Explain Before Asking**: Every interruption details why a choice matters and Brain X's recommended action, along with its confidence and consequences.
- **Law 3 — Human Override**: Humans always own the mission; Brain X never silently alters goals.
- **Law 4 — Progressive Disclosure**: Show outcomes by default; show reasoning graphs and details only on request to minimize cognitive overhead.
- **Law 5 — Cognitive Calm**: Actively reduce uncertainty, never increase it. Avoid restless indicators, constant spinning loaders, and redundant interruptions.
- **Law 6 — Stable Mental Model**: One state maps to exactly one representation everywhere. Brain X must never present equivalent cognitive situations differently without a justified contextual reason.
