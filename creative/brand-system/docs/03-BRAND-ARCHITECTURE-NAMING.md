# Brand Architecture and Naming

## Recommended model
Use a branded-house architecture. `Axiom Studio` is the masterbrand. Customer-facing capabilities use clear endorsed descriptors; engines and phase names remain internal unless they improve comprehension.

## Naming grammar
- Masterbrand: `Axiom Studio`.
- Product spaces: `[Discipline] Studio` only for durable user-visible environments.
- Systems: `[Outcome] System` for cross-product capabilities.
- Engines: `[Function] Engine` for internal architecture or expert documentation.
- Panels: `[Object/Task] Panel` for UI regions.
- Packages: concise technical nouns with versioning.
- Modes: familiar behavioural terms such as Preview, Review, Apply and Replay.

## Public versus internal language
Lead public communication with user outcomes. Use internal architecture names only when they clarify trust, extensibility or integration. Do not expose phase numbers in marketing.

## Naming checks
Hierarchy, pronunciation, searchability, confusion, localisation, legal screening, UI length and future extension.
