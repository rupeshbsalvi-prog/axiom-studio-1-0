# Axiom Sans source notice

These private R1 sources derive from Space Grotesk 2.0 by Florian Karsten and the Space Grotesk Project Authors. The upstream source is https://github.com/floriankarsten/space-grotesk and is licensed under the SIL Open Font License 1.1 included in `OFL.txt`.

R1 renames the family to Axiom Sans, establishes Regular and Display source roles, preserves the inherited Latin language coverage, anchors, kerning, and metrics, and adds an optical-size designspace for private evaluation. The Display source currently uses the inherited bold geometry as a high-contrast evaluation endpoint; Axiom-specific outline changes remain pending visual approval.

No compiled font binary from these sources is approved for distribution or product use.
