# Prompts Directory

This directory contains the raw prompt source files used to generate the visual assets for Axiom Studio.

## Standards (AES-1.0)
- Prompts must be saved as text files (`.txt`) with the lowercase naming convention: `[category]_[element]_[variation].txt`.
- Every prompt should specify the target model and parameters in its sibling metadata `.json` file in `creative/metadata/`.
