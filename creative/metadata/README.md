# Metadata Directory

This directory contains the JSON metadata schema records for all generated assets.

## Standards (AES-1.0)
- Metadata records must match their asset names: `[category]_[element]_[variation].json`.
- Each record must include fields for asset identifier, version, model, parameters, aspect ratio, resolution, file size, licensing rights, and the quality gate verdict.

## External Motion Export Intake

- Animos may be used manually to create MP4 or WebM motion assets from user-owned media.
- Only the exported media may enter the project; do not copy or embed Animos templates, editor code, or site assets.
- Record Animos as the source tool, the export settings, input ownership, and confirmed usage rights in the asset metadata.
- Keep an export out of production when its usage rights are not confirmed.
- Uploading project media and starting an export remain explicit user actions; no automated transfer or render is authorized.
