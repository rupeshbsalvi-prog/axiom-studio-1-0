Wire Photo Studio intent to Imagine X director plan, object proposal, user acceptance, AXPKG persistence, and export.

Add multi-agent traces, provider fallbacks, repair loops, studio-specialist prompts, memory-backed routing, and eval gates.

## Phase B7 - Large Project Orchestration

Add hierarchy-based work distribution, task packet execution, dependency tracking, partial success recovery, per-deliverable progress, recomposition gates, and campaign-scale validation.
