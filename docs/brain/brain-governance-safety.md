# Imagine X Governance and Safety

[Back to docs index](../README.md)

## Purpose

Keep Axiom Imagine X powerful without giving it unauthorized control over project truth.

## Governance Rules

- Imagine X proposals are advisory by default.
- Accepted proposals become semantic command drafts.
- User or policy approval is required before authoritative mutation.
- Provider errors and model limitations must be surfaced.
- Imagine X must preserve exact user-provided names, text, counts, colors, and brand requirements.
- Imagine X must not claim certainty when provider output was not validated.

## Safety Checks

- Text integrity.
- Object count.
- Brand compliance.
- Layout bounds.
- Prompt requirement coverage.
- Provider failure detection.
- Editability check.
- Provenance completeness.

## Audit Requirement

Every accepted Imagine X-assisted change must record intent, provider route, proposal ID, acceptance actor, and resulting command/event reference.

## Locked Baseline

Changes require an ADR.
