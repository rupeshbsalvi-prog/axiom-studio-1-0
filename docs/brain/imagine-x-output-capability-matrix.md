# Imagine X Output Capability Matrix

[Back to docs index](../README.md)

## Purpose

Define what Axiom Imagine X must eventually produce across studios.

## Matrix

| Studio | Imagine X Must Produce | Senior-Level Standard |
|---|---|---|
| Photo | layered image/poster plans, masks, retouch directions, prompt refinements | realistic composition, exact text, editable layers |
| Vector | logo concepts, SVG/path plans, icon systems, shape hierarchies | clean geometry, scalable structure, brand fit |
| Motion | timeline plans, keyframes, easing, transitions, render instructions | rhythm, pacing, cinematic flow |
| Video | edit plan, shot order, overlays, captions, color direction | story clarity, production timing, export readiness |
| Typography | font pairing, hierarchy, spacing, specimen systems | professional type taste, readable hierarchy |
| Brand | identity systems, palette rationale, logo rules, tone | consistency, governance, reusable tokens |
| UI/UX | user flows, wireframes, screen designs, components, prototypes | ergonomic product design, responsive systems, handoff readiness |
| Whiteboard | diagrams, journey maps, planning boards | clear structure, relationships, facilitation value |
| Presentation | deck outline, slide layouts, narrative arc, speaker notes | executive clarity, persuasive flow |
| Asset Hub | asset tagging, reuse suggestions, collection strategy | production organization and metadata quality |
| Axiom AI | agent traces, model reports, learning summaries | explainable intelligence and user control |

## Output Depth Levels

- Level 1: advisory text plan.
- Level 2: structured editable object proposal.
- Level 3: provider-generated candidate plus critique.
- Level 4: repaired and validated candidate.
- Level 5: accepted semantic command proposal ready for runtime.
