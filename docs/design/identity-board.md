# Axiom Identity Board Specification

This document captures the visual identity board framework, brand positioning, and creative design principles (DNA) of the Axiom Creative Platform.

> **Baseline Update (ADR-0004, 2026-08-01):** The [Brand System candidate](../../creative/brand-system/README.md) is available for governance and roadmap review. Its draft colors, typography, logo guidance, CSS, and React implementation do not replace this identity baseline or current runtime assets without explicit approval.

## 1. Axiom DNA Canvas

### Brand Personality & Archetype
- **Archetype Blend**: **The Creator** (focused on expression, execution, and clean canvas structures), **The Sage** (delivering deep analytical knowledge and memory graph traces), and **The Magician** (generating automated creative planning out of simple user intent).
- **Core Personality**: Calm, professional, and timeless. It acts as a confidence-building workspace for designers, avoiding overly energetic or playful AI aesthetics.

### Emotional Targets
- **Curiosity**: 100%
- **Precision**: 100%
- **Confidence**: 100%
- **Delight**: 80%
- **Playfulness**: 30% (retained only for micro-cues)

## 3. Design Principles (Design Laws)

1. **Intent Before Interface**: Interfaces remain minimal. Users supply intent, and the UI adapts dynamically.
2. **Intelligence Without Noise**: AI suggestions are ambient and advisory. Never interrupt user focus.
3. **Motion Must Have Purpose**: Animations convey spatial relations or processing state; never animate for decoration.
4. **Glass Is Functional**: Translucency represents layer depth and workspace hierarchy.
5. **Depth Conveys Meaning**: Z-index represents active states. Background is infinite space.
6. **AI is a Collaborator**: The intelligence layer suggests options, but final certification belongs to the user.
7. **Every Pixel Explains Itself**: No redundant grids, decorations, or margins.
8. **Performance Is Part of Design**: Smooth frames and low latencies build user trust.
9. **Consistency Over Novelty**: Maintain UI patterns across all studios.
10. **Creativity Without Complexity**: Professional-grade output through clear planning.
