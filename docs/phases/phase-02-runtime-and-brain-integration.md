## Goal

Wire core product flows to backend services, Axiom Brain, provider status, project persistence, export, and replay/audit concepts.

- FastAPI app foundation.
- Axiom Brain planning endpoint or local service boundary.
- Provider Connector Hub.
- Auth/User System baseline.
- Replay Audit Panel baseline.
- Export System baseline.
- First semantic command contract.

## Acceptance Criteria

- Brain proposals are visible and accept/rejectable.
- Provider status is explicit.
- Project data persists and restores.
- Replay/audit status is visible even if certification is partial.
