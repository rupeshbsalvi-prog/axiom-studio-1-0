# Phase 03 - Studio Expansion

[Back to docs index](../README.md)

## Goal

Deepen studios beyond scaffolds using shared shell, canvas, project, Brain, provider, export, and replay systems.

## Planned Order

1. Photo Studio vertical MVP.
2. Vector Studio.
3. Brand Studio and Asset Hub.
4. Typography and Presentation.
5. Motion and Video.
6. Whiteboard and collaboration.
7. Axiom AI Studio deep memory and model analytics.

## Acceptance Criteria

- Studios reuse shared components instead of duplicating foundations.
- Studio payloads persist through AXPKG.
- Mutating actions are represented as commands or staged drafts.
- Exports and provider errors are user-visible.
