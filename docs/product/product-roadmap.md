# Product Roadmap

[Back to docs index](../README.md)

## Phase 00 - Documentation Foundation

Create locked documents and decision rules.

## Phase 01 - Product Shell

Create the Workspace Hub and Studio Workspace shell, studio registry, Mission Control, local state, and canvas foundation.

## Phase 01B - Landing Experience Foundation

Create the public Landing Experience, application entry routing, studio explorer, intelligence story, pricing entry, marketplace preview, community links, accessibility fallbacks, and cross-platform responsive behavior.

## Phase 02 - Runtime and Brain Integration

Add API, provider hub, Imagine X proposal flow, project persistence, replay/audit shell, and export foundation.

## Phase 03 - Studio Expansion

Deepen studios in the planned order: Photo, Vector, Brand, Asset Hub, Typography, Presentation, Motion, Video, Whiteboard, Axiom AI.

## Phase 04 - Desktop Productization

Add Tauri filesystem, secure storage, desktop exports, installers, updater, crash logging, and offline-first workflows.

## Phase 05 - Enterprise and Collaboration

Add collaboration, RBAC, audit bundles, governance reports, shared workspaces, and plugin marketplace foundations.
