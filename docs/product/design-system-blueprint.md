# Design System Blueprint

[Back to docs index](../README.md)

## Visual Identity

Axiom Studio 1.0 uses a professional Prism Glass system: restrained glass, obsidian/dark work surfaces, warm gold accents, precise borders, compact controls, and clear hierarchy.

## UI Rules

- Use compact tool-first interfaces.
- Prefer icon buttons with tooltips for repeated tools.
- Keep cards for repeated items, panels, and modals.
- Do not turn the working app into a marketing landing page.
- Use consistent rails, docks, headers, inspectors, and panels.
- Text must fit inside buttons, panels, cards, and rails at desktop and mobile widths.

## Core Tokens

- Background: obsidian, stone, graphite.
- Accent: champagne gold and restrained amber.
- Status: green ready, amber warning, red failure, blue informational.
- Radius: compact, mostly 8px or less for work surfaces.
- Motion: fast, minimal, functional.

## Component Families

- Shell surfaces.
- Tool buttons.
- Segment controls.
- Inspector fields.
- Timeline primitives.
- Layer rows.
- Status badges.
- Provider cards.
- Command rows.
