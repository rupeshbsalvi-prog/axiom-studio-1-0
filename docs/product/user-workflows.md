# User Workflows

[Back to docs index](../README.md)

## Create From Intent

1. User enters through Landing Experience, Workspace Hub, guest entry, or a validated shared link.
2. User opens Mission Control or a selected studio.
3. User enters an intent through text, drawing, and future voice input.
4. Axiom Imagine X creates a director-level plan.
5. User reviews plan, aspect ratio, canvas size, aesthetic direction, provider route, and editable output strategy.
6. User accepts the plan.
7. Runtime creates semantic objects.
8. Studio opens with editable result.

## First-Time Public Entry

1. User opens Axiom Studio 1.0.
2. Landing Experience introduces the platform philosophy.
3. User explores Axiom Imagine X, Axiom Brain X, studios, gallery, marketplace, and pricing.
4. User chooses Start Creating, Start Free Trial, Sign In, or Continue as Guest.
5. Router sends user to Workspace Hub, Guest Workspace, or selected studio path.

## Authenticated Workspace Entry

1. User opens Axiom Studio 1.0.
2. User is recognized as authenticated.
3. Workspace Hub opens by default.
4. User resumes recent project, starts from template, opens recommendations, manages billing, or selects a studio.

## Edit Existing Project

1. User opens recent project.
2. AXPKG restores manifest, canvas slices, studio payloads, assets, and Imagine X slice.
3. Active studio renders certified state.
4. User edits objects through canvas and inspector.
5. Runtime logs accepted semantic changes.

## Recover Autosave

1. Mission Control detects recovery session.
2. User previews project metadata.
3. User restores or discards session.
4. Project memory records the decision.

## Export Work

1. User opens Export System.
2. User chooses format and preset.
3. Export validates project state and provider/runtime route.
4. Export creates artifact.
5. Replay/audit panel records result path or failure.
