# Marketplace and Monetization

[Back to docs index](../README.md)

## Purpose

Define the monetization model beyond the core subscription so Axiom can scale as a platform.

## Monetization Layers

Axiom Platform has three monetization layers:

1. Software Subscription: Free Trial, Creator, Professional, Business, Enterprise, Education.
2. Marketplace Revenue: templates, plugins, MCP servers, AI agents, assets, packs, extensions, and themes.
3. Compute and AI Usage: AI credits, premium model access, rendering, generation minutes, and storage expansion.

## Marketplace Categories

The marketplace may include:

- Templates.
- Prompts.
- Workflows.
- Assets.
- Components.
- Studio packs.
- AI agents.
- Themes.
- Plugins.
- MCP servers.
- Brand packs.
- UI kits.
- Motion packs.
- Icon packs.
- Font packs.
- Enterprise integrations.
- Training courses.
- Certification programs.

## Marketplace Requirements

Each marketplace item must define:

- Name.
- Publisher.
- Version.
- Category.
- Compatibility.
- Supported studios.
- Required permissions.
- License.
- Price.
- Trial availability.
- Update policy.
- Security level.
- Offline support.
- Support contact.
- Usage metrics.

## Compute and AI Usage

Usage products may include:

- Image generation credits.
- Video generation minutes.
- Motion rendering credits.
- Voice generation minutes.
- 3D rendering credits.
- High-speed rendering.
- GPU rendering hours.
- Premium model access.
- Cloud storage expansion.
- Team collaboration storage.

## Governance

Marketplace and usage systems must support:

- Purchase audit logs.
- Refund policies.
- Enterprise approval workflows.
- Admin allowlists and blocklists.
- License transfer policies.
- Security review for plugins and MCP servers.
- Usage limits by workspace, role, and billing plan.

## User Experience

Marketplace must be available from:

- Landing Experience.
- Workspace Hub.
- Studio Workspace.
- Licensing Dashboard.
- Provider Connector Hub.

Marketplace installation must be explicit and reversible.
