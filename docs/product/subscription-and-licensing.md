# Subscription and Licensing

[Back to docs index](../README.md)

## Purpose

Define the commercial SaaS subscription, trial, billing, licensing, and usage experience for Axiom Studio 1.0.

## Philosophy

The subscription experience must communicate value, transparency, and scalability. It should not feel like a forced paywall.

Users must be able to:

- Compare plans.
- Start a free trial.
- Upgrade or downgrade.
- Estimate AI usage.
- Understand commercial licensing.
- Manage subscriptions, invoices, devices, storage, and credits.

## 30-Day Free Trial

Every new user receives a 30-day free trial.

Included:

- Access to all studios.
- Axiom Imagine X.
- Axiom Brain X capabilities exposed through Imagine X.
- AI planning.
- Templates.
- Project Hub.
- Marketplace browsing.
- Community assets.
- Cloud sync.
- Cross-platform access.
- Version history.
- Non-destructive editing.

Optional restrictions:

- Limited AI credits.
- Limited cloud storage.
- Optional watermark on commercial exports.
- No enterprise administration.
- Limited premium templates.

The product should show a clear countdown, for example:

`Day 12 of 30 remaining`

Upgrading must not remove or reset projects.
