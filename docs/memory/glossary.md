# Glossary

[Back to docs index](../README.md)

## Axiom Imagine X

The intelligence model/layer that acts as the senior creative director and production mastermind across Axiom Studio 1.0. It plans, critiques, repairs, routes, and learns. It proposes structured creative work but does not own final authority.

## Axiom Brain

Legacy/internal shorthand for the Axiom Imagine X intelligence layer.

## AXPKG

The portable Axiom project package format. It owns project durability, autosave, recovery, and interchange.

## Deterministic Runtime

The authoritative runtime that applies semantic commands, records replayable events, and certifies state.

## Projection

Visual output derived from authoritative state. GPU, previews, thumbnails, and rendered exports are projections unless explicitly certified.

## Semantic Command

A structured, replayable instruction that changes authoritative state after validation.

## Studio

A domain-specific creative surface that uses shared Axiom systems for canvas, project, brain, providers, export, and replay.
